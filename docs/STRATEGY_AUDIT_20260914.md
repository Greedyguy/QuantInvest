# 전략 성과 감사 — 2026-09-14

## 결론

기존 전략의 마이너스 성과는 소액 계좌의 최소주문 제약만으로 설명되지 않는다.
1억원·최소주문 0원 조건에서도 실행 가능한 종목 목표는 학습, 검증, 최종평가
구간 모두 마이너스였다. 기존에 표시된 장기 수익률은 하위전략의 합성 수익률을
상위 노출도에 곱한 값이며, 실제 종목 목표와 주문 체결을 재생한 결과가 아니다.

하위전략의 현금을 보존하면 손실과 낙폭은 크게 줄지만, 평균 목표 노출이 8.17%,
210만원 계좌의 평균 실현 노출은 3.26%까지 떨어진다. 따라서 현금 보존은 유효한
리스크 통제이지만 그 자체로 자산 증식 전략은 아니다.

## 고정한 검증 조건

- 데이터: `20190101_20251113` 캐시 세대, 2,464종목
- 학습: 2020-01-01~2023-12-31
- 검증: 2024-01-01~2024-12-31
- 최종평가: 2025-01-01~2025-12-31 (실제 캐시 종료일 2025-11-13)
- 체결: 신호 다음 거래일 시가, 정수주, 매도 우선, 가격 이탈 재확인
- 비용: 매수·매도 수수료, 모든 매도의 거래세, 진입·청산 슬리피지
- 계좌: 210만원·최소주문 5만원과 1억원·최소주문 0원 비교

포트폴리오가 만들어진 우연한 결과다.

## 손실 원인 분해

1. **합성 수익률과 실제 목표의 불일치**

   기존 `run_backtest()`는 하위전략 에쿼티 수익률을 혼합한 뒤 노출도를 곱한다.
   종목별 목표, 정수주, 다음 날 시가, 주문 누락을 거치지 않으므로 실전 전략의
   검증값으로 사용할 수 없다.

2. **하위전략 현금의 제거**

   기존 결합기는 하위전략의 `__CASH__`를 제거하고 남은 위험자산을 상위 노출도까지
   다시 확대한다. 감사 방식으로 현금을 보존하자 평균 목표 노출은 기존의 23.6%만
   남았다. 즉 기존 목표 노출의 상당 부분은 독립적인 매수 신호가 아니라 현금 제거로
   만들어진 노출이었다.

3. **신호 자체의 음(-)의 성과**

   1억원 계좌에서도 기존 목표는 학습 -48.37%, 검증 -16.74%, 최종평가 -3.05%였다.
   210만원 제약을 제거해도 회복되지 않으므로 최소주문은 주원인이 아니다.

4. **높은 회전율과 비용**

   기존 목표의 목표 회전율 합계는 학습 7,164%, 검증 1,102%, 최종평가 880%였다.
   1억원 계좌의 명시적 수수료·세금만 초기자금 대비 학습 7.97%, 검증 0.78%,
   최종평가 0.50%였다. 비용이 손실 전부를 만들지는 않았지만 약한 신호를 더
   악화시켰다.

5. **상승장 참여 실패**

   같은 캐시에서 2025년 KOSPI는 약 +73.85%, KOSDAQ은 약 +33.75%였지만 기존
   실행 목표는 -3.05%였다. 평균 목표 노출 21.53%와 잦은 교체로 상승 추세를
   충분히 보유하지 못했다.

6. **소액 계좌에서 전략 정체성 붕괴**

   기존 목표의 평균 실현 노출은 1억원 33.37%, 210만원 23.80%였고 평균 보유
   종목 수는 각각 11.51개와 3.13개였다. 현금 보존 정책은 210만원에서 평균
   보유 종목 0.84개, 실현 노출 3.26%로 축소되었다.

## 해석과 다음 단계

현금 보존 정책은 현재 전략의 안전판으로는 유지할 가치가 있다. 다만 이 정책을
기존 전략의 개선판이나 새로운 수익원으로 간주하면 안 된다. 다음 단계는 현금
보존 코어와 독립된 저회전 시장참여 슬리브를 그림자로 추가하는 것이다.

새 슬리브는 KODEX 200 같은 실제 매수 가능한 ETF 중심으로 만들고, 추세가 회복될
때 단계적으로 재진입하며, 210만원 계좌에서도 최소 1주 단위로 의도한 노출을 만들
수 있어야 한다. 채택 기준은 파라미터를 고른 학습구간이 아니라 2024 검증과 2025
최종평가, 그리고 2026 저장 신호 재생에서 비용 차감 후 동시에 양(+)의 수익률을
내는지 여부로 둔다.

## 재현 명령

전체 신호를 다시 계산하려면:

```bash
PYTHONPATH=. python scripts/audit_strategy_validation.py
```

저장된 목표로 계좌·최소주문 조건만 빠르게 다시 계산하려면:

```bash
PYTHONPATH=. python scripts/audit_strategy_validation.py \
  --legacy-targets reports/<legacy-targets>.parquet \
  --cash-preserved-targets reports/<cash-preserved-targets>.parquet
```
