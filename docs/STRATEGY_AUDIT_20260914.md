# 전략 성과 감사 — 2026-09-14 (ETF 캐시 보정판)

## 정정 사항

최초 감사 실행은 일반 종목과 다른 파일 범위를 쓰는 ETF 캐시를 누락했다. 종목별로
요청 기간을 가장 잘 덮는 캐시를 선택하도록 로더를 고친 뒤 KODEX 200을 포함한
2,730종목으로 전 결과를 다시 계산했다. 아래 수치가 보정된 최종 결과다.

## 결론

기존 복합전략은 최초 결과처럼 전 구간에서 큰 손실을 낸 것은 아니다. 하지만
1억원 기준 학습구간 -2.58%, 2024년 검증 -2.63%로 장기적인 초과수익 근거가
약하고, 2025년 강한 상승장에서만 +12.38%를 냈다. 210만원 계좌도 학습 +0.90%,
검증 -2.13%, 2025년 +14.20%였다.

기존에 표시된 합성 백테스트 수익률은 여전히 실전 검증값으로 사용할 수 없다.
하위전략 에쿼티 수익률을 혼합한 값으로 실제 종목 목표, 정수주, 익일 시가,
최소주문, 주문 누락을 재생하지 않기 때문이다.

## 고정한 검증 조건

- 데이터: 2025-11-13 지수 스냅샷과 종목별 최장 유효 캐시, 2,730종목
- 학습: 2020-01-01~2023-12-31
- 검증: 2024-01-01~2024-12-31
- 최종평가: 2025-01-01~2025-11-13
- 체결: 신호 다음 거래일 시가, 정수주, 매도 우선, 가격 이탈 재확인
- 비용: 매수·매도 수수료, 모든 매도의 거래세, 진입·청산 슬리피지
- 계좌: 210만원·최소주문 5만원과 1억원·최소주문 0원 비교

## 남아 있는 문제

1. **합성 수익률과 실제 목표의 불일치**

   기존 `run_backtest()`는 종목 주문 대신 하위전략 합성 수익률을 사용하고,
   전체 표본 변동성으로 과거 전체를 한 번에 조정한다. 감사 경로는 이 계산을
   사용하지 않는다.

2. **검증구간의 음(-)의 성과**

   계좌 크기와 현금 보존 여부에 관계없이 2024년은 약 -2%였다. 2025년 상승장
   수익만으로 전략 전체의 안정적인 알파를 입증하기 어렵다.

3. **높은 회전율과 비용**

   기존 목표의 목표 회전율 합계는 학습 4,151%, 검증 346%, 최종평가 645%였다.
   1억원 계좌의 명시적 수수료·세금은 초기자금 대비 각각 4.89%, 0.44%,
   0.66%였다.

4. **소액 계좌의 포트폴리오 축소**

   평균 실현 노출은 기존 목표 기준 1억원 29.71%, 210만원 25.13%였고 평균 보유
   종목 수는 각각 10.44개와 2.43개였다. 실전 소액계좌는 백테스트와 다른 집중
   포트폴리오가 된다.

5. **현금 보존은 수익원이 아님**

   하위전략 현금 보존 시 평균 목표 노출은 30.66%에서 25.04%로 낮아지고 회전율과
   비용은 줄지만, 검증 성과는 개선되지 않았다.
